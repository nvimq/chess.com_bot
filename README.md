# ♟️ chess.com_bot

> **Educational project** — изучение антибот-систем chess.com и автоматизации игры.

Этот проект создан **исключительно в образовательных и исследовательских целях**.

**Использование данного ПО против активных игровых платформ может привести к блокировке аккаунта и другим санкциям.**

## 🧠 Цель

Изучение и анализ:
- механик антибот-систем онлайн-платформ
- методов компьютерного зрения для анализа доски (OpenCV)
- автоматизации ввода через pyautogui
- логики шахматного движка (python-chess)
